# Afrin Fathima React Portfolio

Run with Node.js installed:
1. `npm install`
2. `npm run dev`

Build: `npm run build`

The CV download is wired to `public/Afrin-Fathima-CV.pdf`. Replace the abstract project preview blocks in `src/main.jsx` with your own exported project images and add verified case-study details and social links before publishing. The content is based on your uploaded CV; placeholder project artwork is not your original work.
